## Principais funcionalidades
- Escrever texto em markdown formatado
- Salvar notas localmente

## Stack utilizada
- *Frontend*: React, TailwindCSS, Lucide Icons
- *Linguagens*: Typescript
- *Testes*: -
- *Outros*: Vite

## Setup

### Instalação
```bash
git clone [https://github.com/JaianeOliveira/tapnotes.git](https://github.com/JaianeOliveira/tapnotes.git)

cd tapnotes

npm install
```
### Configuração de ambiente
1. Copie `.env.example` para `.env`
2. Preencha as variáveis de ambiente

### Rodando localmente
```bash
npm run dev
```
